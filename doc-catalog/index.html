Model catalog

As of 4 November 2026. This catalog is a filter list, not a leaderboard. Hard filters come from AI engineering. The checkpoint must emit spans. The license must allow the intended use. V1 must run the weights on the host.

This catalog copies reported F1 values from the named card or paper. They are not edgepii results. Where two sources disagree, both numbers appear. The golden set is the ranker.

Do not list damo/nlp_raner_named-entity-recognition_chinese-base-generic as a PII model. The output shape is a span, and the types are generic NER (issue 274).

The adapter accepts a UIE hit only when the surface equals source[start:end]. If the live card uses an inclusive end, the adapter can try end+1 one time. If neither slice matches, the adapter drops the hit. The adapter does not search the string for the surface.

Selection rule

  1. Reject a checkpoint that does not return character offsets or BIO tags with offsets.
  2. Reject a checkpoint whose license blocks the product.
  3. Reject a remote API in v1.
  4. Run the survivors on the dev freeze with the scorer.
  5. Read the misses.
  6. Promote a preset only after the sealed freeze meets the floors in the evaluation spec.

Pinning

Each preset records hub, repo_id, revision, and sha256 of the weight file. A floating main branch is not a preset. The locator prints the revision in debug output. It does not print the source string.
