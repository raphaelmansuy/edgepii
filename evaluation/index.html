Public score

Exact-span F1 on two pinned public PII corpora. A prediction counts only when the type, the start, and the end all match gold. A one-character shift is a miss, because one character is enough to break a mask.

The two corpora

KeyCorpusLicenseRole
nemotron-piiNVIDIA Nemotron-PII, test splitCC-BY-4.0 In domain. The en-closed checkpoint trains on this distribution
gretel-finance-enGretel synthetic PII, finance, English test splitApache-2.0 Out of domain. Finance documents and SWIFT messages

Each corpus is pinned by commit revision, byte count, and sha256. A download that does not match stops the run, because a moved file makes an old score unreadable.

The finding that matters

The en-closed checkpoint scores 0.995 on PERSON in domain and 0.048 out of domain. It learned where a name sits in a synthetic persona note, not what a name is. The model card reports F1 0.9628 on its own test split, and that number alone would have shipped the lane.

This is why the harness exists. Read the full analysis in the first public score.
