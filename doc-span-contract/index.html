Span contract

This file is the product. Every detector, preset, and test must satisfy it. The five whys explain why the contract has this shape. See Five whys and ADR 0001.

Job

Input: one source string, plus an optional subset of taxonomy types.

Output: a list of spans. Each span names a type, a start offset, an end offset, the slice text, and an optional score.

The job is location. Redaction is a pure function of those spans. The public API specifies redaction. It is not a second product.

FieldRule
taxonomy_versionThe taxonomy file that mapped labels for this call
typeA name in that taxonomy. Never a raw model label
startInclusive index into the source string
endExclusive index into the source string
textMust equal source[start:end]
scoreA float from 0 to 1, or null when the detector has no scoredetector_idStable id of the detector that proposed the span
raw_labelThe label before the map. For audit. Not a public type

Indexes are Python string indexes. They count Unicode code points. They do not count UTF-8 bytes. A caller that stores bytes must convert before the call and after it.

Invariants

A result is valid only when all of the lines below hold.

  1. 0 <= start < end <= len(source) for every span.
  2. text == source[start:end] for every span.
  3. type is a member of taxonomy_version.
  4. The locator did not change the source string before it computed offsets.
  5. Spans in the public list do not overlap, after the merge step in the architecture.
  6. A span whose type the caller excluded is absent from the list.
  7. Exception text and INFO logs do not contain the source string or text.

If a detector breaks invariant 1 or 2, the locator drops that span. The locator increments a drop counter. The locator does not repair the offset by searching for text elsewhere in the string. A search can attach the span to the wrong copy.

Offsets and BIO

BIO and BILOU train the head. They are not the public result. A token classifier can use them inside an adapter. The adapter must map tokens back to character offsets before it returns. The Hugging Face pipeline can do that when the tokenizer returns offsets (token classification).

The same source string is the only legal target of those offsets. A second string, even a trimmed copy, is a defect.

Success and failure

Success: every in-scope mention in the golden set has a span with the right type and the same start and end.

FailureWhat the caller seesWhy it matters
MissNo span on a gold rangeThe characters can leave the trust boundary
Wrong typeRight range, wrong typeThe wrong policy runs
ShiftThe range starts or ends on the wrong characterA tail leaks, or the mask deletes a neighbor
Extra spanA span on text that is not in scopeThe task loses words it needed
OverlapTwo public spans share a characterThe mask order is undefined
Bad slicetext is not source[start:end]The audit is false

A miss on a high-severity type is the costly failure. An extra span is a utility cost. The evaluation spec scores them apart. It does not fold them into one unlabeled PII score.

Empty and bad input

An empty string returns an empty span list and the active taxonomy version. That result is success.

None is an invalid call. The library raises TypeError. The message does not echo a value.

A type name outside the taxonomy is an invalid call. The library raises UnknownType. The call does not run a detector.

Non-goals for v1

  • Image OCR. The caller passes text. A scan stays outside this library.
  • A legal opinion that a type is personal data in a given country.
  • Training a new checkpoint inside the library.
  • A network service. The call stays inside the caller program.
  • Fuzzy restore of a model answer. The parent note forbids it (Hide names and phones).
  • Storage of the source string or of a reverse map. The caller holds both.

Relation to mask and restore

The parent product is mask, then call, then restore. edgepii owns the first find. A small redact function can replace spans with placeholders and return the map to the caller. The function does not keep the map. Secrets never enter the map. See ADR 0004.

The outbound string is safe only when a second local pass finds no high-severity span left in it. That second pass uses the same locator. It is a product rule in the evaluation spec, not a new detector.
