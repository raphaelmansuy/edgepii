Glossary

Use these names in code, docs, and reviews. If a synonym appears in a model card, map it here and do not reuse the synonym as a public name.

TermMeaning
source stringThe str the caller passed to locate. The only legal target of an offset
offsetA Python index into the source string. Code points, not bytes
spanOne half-open range plus a public type, the slice, a score, a detector id, and a raw label
typeA name in the active taxonomy. Example: EMAIL
taxonomyThe versioned type list. Current version: 2026.11
label mapThe table from a raw model label to a type
raw labelThe string the model or the rule emitted before the map
detectorAn object that returns hits for a source string
hitA private range with a raw label. Not a public span yet
locatorThe object that maps, checks, and merges hits into a result
presetA named set of detectors and a pinned revision
laneA family of detectors. Rules, closed encoder, open schema, or Chinese schema
mergerThe only module that resolves overlapping spans
exact-span F1Precision and recall where a match needs the same type, start, and end
missA gold span with no overlapping prediction
extra spanA prediction that overlaps no gold span
golden setLabeled rows with frozen offsets. Split into a dev freeze and a sealed freeze
dev freezeThe golden subset builders can use to tune a caller score floor
sealed freezeThe golden subset for one ship decision
leakageA gold high-severity slice still present at its offsets after redact
vaultThe map from placeholder to slice. The caller holds it. The library does not
classThe policy group of a type. secret, gov_id, payment, contact, person, or quasi
UNCONFIRMEDA number or a rank with no measure on our golden set

Do not alternate

SayDo not also say
spanentity, hit, finding, match, as a public name
source stringdocument, text, payload, as the offset target. "text" is the slice field only
typelabel, tag, category, as the public name. "raw label" is the private one
presetmodel, when you mean the wired stack. The model is the checkpoint
locatorpipeline, engine, analyzer
golden setbenchmark, when you mean our freeze. A public benchmark keeps its own name
vaultmap, in code. Prose can say "the vault". Do not also say "the store"

PII means personally identifiable information in this set. The law can say personal data and mean a wider set. Counsel owns that wider set. The library owns the taxonomy.
