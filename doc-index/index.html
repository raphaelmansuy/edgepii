edgepii specification

Status: implemented. This set records the problem, the research, the public API, and the build plan. The library, the tests, and the demo now follow this set. See the project README for install and quickstart.

edgepii is a Python library that locates personally identifiable information (PII) in text. The library returns typed character spans on the same string the caller passed. The library does not decide that a whole document is sensitive.

This set records the problem, the research, the public API, and the build plan. Card scores in the research notes are not ship gates. See the evaluation spec.

Origin notes, Ideas Lab:

  • Locate PII spans in text
  • Hide names and phones before the AI sees them
  • Span pipeline (detect, then classify)

Decision in one page

Keep a locator that returns {type, start, end, text, score} on the source string. Ship two default lanes after a frozen golden set, not before it.

Closed encoderen-closedantoniogr7/pii-identifier-v0.1The team freezes the type list, the text is English, and latency matters
Open schemamulti-openfastino/gliner2-privacy-filter-PII-multiThe caller must change types at call time

A classic BERT control stays available as preset en-bert (ab-ai/pii_model). BERT-family token classification is enough when the taxonomy and the domain stay fixed. See when the encoder is enough.

Rules for email, phone, IBAN, and payment cards run beside the model. They do not replace it for names. Chinese schema extraction is an optional ModelScope adapter, not a default. See the catalog.

Assessment, November 2026

The library is at 0.2.0. It locates spans, masks them, and restores them, and the span contract holds. The assessment records what is measured, three defects that a reader can reproduce, and where the field moved ahead of the library: the tool-call plane, surrogate replacement, and quasi-identifier combinations.

What v1 will not do

V1 will not send the source string to a cloud PII API. V1 will not ask a chat model to rewrite the text. V1 will not treat a document label as success. V1 will not copy a leaderboard F1 into a ship gate. The numeric floors stay open until the golden set exists. Call that open state UNCONFIRMED.
